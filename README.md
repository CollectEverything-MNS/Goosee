# Goosee Generator

## Installer de le projet

-   Cloner le projet

```
git clone git@github.com:CollectEverything-MNS/Goosee.git
```

-   Pour développer en local vous pouvez installer les dépendances du projet :

```
yarn install:project
```

## Démarrer le projet sous docker

### Environnement locale

-   Démarrer le projet

```
yarn start:dev
```

-   Éteindre le projet

```
yarn stop:dev
```

-   Redémarrer le projet

```
yarn restart:dev
```
